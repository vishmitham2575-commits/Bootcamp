PG Complaint Management System
Description
A simple web application to submit and manage PG complaints.

Features
Add complaints
Search complaints
Delete complaints
View complaint status


Technologies Used
HTML
CSS
JavaScript


Project Structure
PG-Complaint-System/
├── project.html
├── script2.js
└── README.md

Setup
Download or clone the project.
How to Run
Double-click project.html or open it using a browser.

Note
Complaints are stored temporarily and will be removed when the page is refreshed.
